# GPSLite - support

Official support repository for the Farming Simulator 25 mod by TFU-dafke.

## Download

Download the published mod from [the original KingMods page](https://www.kingmods.net/en/fs25/mods/81700/gps-lite). KingMods lists **V1.3.0.2** when this support repository was created on 24 October 2026. Include the version in your actual ZIP when reporting a problem.

This repository contains support documents only. Mod source and mod ZIPs are not hosted here.

## Report a problem

[Open a bug report](https://github.com/dafke1305/FS25_GPSLite/issues/new/choose). Include the mod and FS25 versions, map/version, play mode, numbered reproduction steps, expected and actual behaviour, and session logs. Add screenshots or a short video for visual, physics or interaction problems.

See [the full support and privacy guidance](https://github.com/dafke1305/.github/blob/main/SUPPORT.md). For private evidence, use a staff-approved private channel.

Existing authorship, credits and distribution terms of the original mod remain applicable.
